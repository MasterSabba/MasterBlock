# MasterBlock

MasterBlock è un puzzle game minimalista in stile block-blast dove strategia e velocità contano davvero. Posiziona i pezzi sulla griglia 8x8, completa righe e colonne per ottenere punti e cerca di sopravvivere il più a lungo possibile.

Il gioco include:

* Modalità **Standard** per partite rilassanti e infinite
* Modalità **Challenge** con ostacoli casuali che aumentano la difficoltà
* Sistema di punteggio e record salvati localmente
* Interfaccia ottimizzata per desktop e mobile

Fa parte del progetto principale MasterSabba Hub, collegato alla repository centrale.
